# Implement Feature

This skill requires an approved implementation plan.

Do not implement the feature if no approved plan exists.

## 1. Verify prerequisites

Before modifying any files, confirm that all of the following are available:

- the active task or ticket
- the current requirement set
- resolved product-level ambiguities
- an implementation plan
- explicit approval of that implementation plan

If any of these are missing, stop and explain what is missing.

Do not create or infer an implementation plan inside this skill.

If no approved implementation plan exists, suggest using the `plan-change` skill first.
